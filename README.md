## 가입 순서와 코드를 넣는 정확한 위치

절차 자체는 길지 않다. 다만 순서를 헷갈리면 되돌리기 어려운 단계가 하나 있다.

1. 이메일 또는 휴대전화 번호로 가입을 시작한다.
2. **초대 코드(추천인 코드) 칸에 코드가 들어가 있는지 확인한다.** 링크로 들어왔다면 자동 입력되어 있다. 직접 입력할 경우 대소문자까지 그대로 넣어야 한다.

## 초대 보상은 어떻게 지급되나

코드를 넣는 쪽은 대개 "보너스"를 기대한다. 여기서 기대치를 조정할 필요가 있다. 게이트가 친구 초대 이벤트 페이지에 걸어둔 조건은 이렇다.

- 친구 2명을 초대하고, 각자가 입금과 거래 조건을 채우면 초대인 최대 200 USDT, 친구는 각각 최대 100 USDT
- 보상은 현금이 아니라 **바우처(쿠폰) 형태**로 지급되고, 사용 기한이 짧다. 페이지 기준 유효기간이 5일로 명시돼 있다
- 지급은 조건 충족 후 수동 검토를 거친다. 3영업일이 지나도 안 들어오면 고객센터 문의가 필요하다
- 다른 초대 이벤트나 커미션과 중복 적용되지 않는다
- 유효 입금으로 인정되지 않는 경로가 꽤 많다. 내부 계정 간 이체, GateCode 전송, 카드·간편결제 계열 입금(구글페이·애플페이·SEPA·PIX·은행 송금 포함), 지급받은 상품권은 제외된다

정리하면 "가입만 하면 현금이 들어온다"는 식의 기대는 어긋난다. 보상을 받으려면 최소 예치와 거래를 실제로 해야 하고, 나오는 건 수수료를 깎아주는 쿠폰이다.

## 한국 사용자에게 해당하는 제한

이 부분은 검색 결과에서 잘 안 보이는데, 코드를 넣기 전에 알아야 할 내용이다.

- **미국 거주자는 가입 자체가 차단된다.** 미국 IP와 미국 신분증은 등록 단계에서 막힌다.
- **한국은 게이트의 일부 초대 이벤트에서 제외 지역으로 명시돼 있다.** 예를 들어 "친구 2명 초대하고 최대 200 USDT" 형태의 이벤트는 벨기에, 영국, 프랑스, 독일, 네덜란드, 투르키예, 오스트리아, 한국 등을 제한 지역으로 적어 두고 있다. 한국 계정으로는 코드를 넣어도 이 이벤트 보상은 지급되지 않는다는 뜻이다.
- 이벤트 제외와 계정 사용은 별개다. 게이트는 국내 사용자도 가입·거래가 가능하고, 앞서 말한 CODE 제휴도 유지되고 있다.

그래서 한국에서 코드를 쓰는 목적은 "초대 보상 수령"보다 **수수료 할인 적용**에 두는 게 현실적이다. 이벤트 보상을 노리고 코드를 넣었다가 조건 미충족으로 아무것도 못 받는 경우가 흔하다.
